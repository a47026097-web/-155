# دردشة — تطبيق محادثات فورية

تطبيق ويب شبيه بواتساب: حسابات، قائمة جهات اتصال، محادثات فردية فورية، حفظ الرسائل، علامات القراءة، ومؤشر "يكتب الآن".

## كيف تشغّله

تحتاج **Node.js نسخة 18 أو أحدث**.

```bash
cd dardasha
npm install
npm start
```

بعدها افتح المتصفح على: `http://localhost:3000`

## تجربته بين مستخدمين

1. افتح الصفحة وسوّي حساب أول (مثلاً `ali`).
2. افتح نافذة خاصة (Incognito) أو متصفح ثاني وسوّي حساب ثاني (مثلاً `sara`).
3. كل حساب يشوف الثاني بالقائمة اليسرى — اضغط عليه وابدأ الكلام.

لتجربته بين جهازين على نفس شبكة الواي فاي: شوف عنوان جهازك المحلي (مثل `192.168.1.5`) وافتح من الجهاز الثاني `http://192.168.1.5:3000`.

## كيف يشتغل باختصار

- **الحسابات:** كلمة السر تُخزن مشفّرة بـ bcrypt، والجلسة تُدار بـ JWT محفوظ بالمتصفح.
- **الرسائل الفورية:** Socket.IO يفتح اتصال دائم. كل مستخدم ينضم لغرفة خاصة `u:<id>`، والرسالة تُرسل لغرفة المُرسِل والمستقبل معاً حتى تظهر بكل النوافذ المفتوحة.
- **القاعدة:** جدولان فقط — `users` و`messages`.

## قبل ما تنشره على الإنترنت

- غيّر مفتاح JWT: `JWT_SECRET=مفتاح_طويل_وعشوائي npm start`
- شغّله خلف HTTPS (مثلاً Nginx أو Caddy).
- SQLite كافية للتجربة وللاستخدام الخفيف؛ إذا صار عدد المستخدمين كبير انتقل لـ PostgreSQL.
- التطبيق حالياً **ما يدعم التشفير من الطرف للطرف** — الرسائل تُحفظ نصاً بالقاعدة، يعني مالك السيرفر يقدر يقرأها. هذي نقطة مهمة تنتبه لها إذا نويت تستخدمه جدياً.

## المكالمة الصوتية

فوق أي محادثة مفتوحة في زر 📞. المكالمة تشتغل بتقنية WebRTC: الصوت نفسه يمشي **مباشرة بين الجهازين** (peer-to-peer)، والسيرفر يوصّل بس رسائل التفاوض الأولي (offer/answer/ICE) عبر Socket.IO.

**عن "ثقب الجدار الناري":**
- إذا الطرفين على نفس الشبكة المحلية (لوكال)، الاتصال يصير مباشرة بدون أي مشكلة.
- إذا كل واحد على شبكة/راوتر مختلف (عبر الإنترنت)، يحتاج الجهازين يعرفوا عنوانهم العام حتى يوصل الصوت من طرف لطرف من خلال الراوترات — وهاي وظيفة **خادم STUN**. مضفتلك خوادم STUN عامة ومجانية من Google، وتكفي بأغلب الحالات (أكثر من 80% من الشبكات العادية).
- بعض الراوترات عندها NAT مقيّد جداً (Symmetric NAT) ما يكفيها STUN، وتحتاج **خادم TURN** يعيد بث الصوت عبره (مو peer-to-peer مباشر، بس أبطأ شوي وأضمن اتصال). ما جبت لك خادم TURN جاهز لأنه يحتاج استضافة خاصة به (مثل coturn) ومصاريف باندويدث. إذا احتجته لاحقاً:
  1. شغّل خادم [coturn](https://github.com/coturn/coturn) على سيرفر عندك عنوان IP عام.
  2. شغّل التطبيق بـ:
     ```bash
     TURN_URL=turn:your-server-ip:3478 TURN_USER=user TURN_PASS=pass npm start
     ```
  3. راح يضاف تلقائياً لإعدادات الاتصال.

**ملاحظات:**
- المكالمة صوت بس حالياً (بدون فيديو)، وتقدر تضيف فيديو لاحقاً بنفس الطريقة (فقط أضف `video: true` لـ `getUserMedia` واعرض `<video>` بدل الاستماع فقط).
- المتصفح يطلب إذن المايكروفون أول مرة — لازم توافق حتى تشتغل المكالمة.
- إذا الموقع مو على HTTPS (غير localhost)، أغلب المتصفحات تمنع الوصول للمايكروفون؛ هذا قيد أمان بالمتصفح نفسه مو بالتطبيق.
